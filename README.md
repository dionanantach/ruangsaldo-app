# RuangSaldo PWA

Pembungkus PWA untuk web app RuangSaldo (Google Apps Script), di-host di GitHub Pages.
Tidak berisi kode server, token, atau data; hanya memuat web app di layar penuh.

- Isi `config.js` → `EXEC_URL` (deployment "Only myself").
- Settings → Pages → Deploy from branch `main` / root.
- Buka `https://<username>.github.io/<repo>/` di Chrome Android → ⋮ → Instal aplikasi.

Panduan lengkap & troubleshooting: `docs/PWA_SETUP.md` di proyek RuangSaldo.
